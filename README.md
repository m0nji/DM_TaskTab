# DM TaskTab

Dieses Repository enthält nur die **Releases** von DM TaskTab (signiert und notarisiert) und den
Update-Feed für die automatische Aktualisierung.

**Download:** [Neueste Version](https://github.com/m0nji/DM_TaskTab/releases/latest) – DMG öffnen und
DM TaskTab in den Programme-Ordner ziehen. Voraussetzung: macOS 26 oder neuer.
